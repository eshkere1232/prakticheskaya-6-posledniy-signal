# Последний сигнал

Текстовая игра на Python для практической работы №6. Игрок проходит три этапа на полярной станции: находит код, обходит охранного дрона и восстанавливает связь. В игре используются списки, кортежи, множества и словари.

Запуск: `python game.py` (в Windows также `py -3 game.py`). Список команд появится в игре; для подсказки введите `подсказка`.
