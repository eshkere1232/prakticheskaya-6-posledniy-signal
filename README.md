# Последний сигнал — практическая работа №6

Текстовая игра на Python. Герой восстанавливает связь с полярной станции за три этапа: склад, шлюз и радиорубка. На каждом этапе нужно решить задачу и ввести команды.

## Запуск

Нужен Python 3. Запустите из папки проекта:

```text
python game.py
```

На Windows также можно использовать `py -3 game.py`.

Команды выводятся при старте. В любой момент доступны `помощь`, `осмотреться`, `подсказка`, `инвентарь`, `карта` и `выход`. Названия предметов и комнат вводятся по-русски. Загадки можно решить без просмотра кода.

## Коллекции данных

- **Списки:** инвентарь героя и предметы в комнатах.
- **Кортежи:** неизменяемые координаты комнат на карте.
- **Множества:** уникальные выполненные действия и включённые каналы.
- **Словари:** описания комнат и предметов, текущее состояние игры.

Три этапа содержат разные задачи: найти код, обойти дрона и восстановить передачу сигнала. Файл `test_game.py` проверяет прохождение и важные ограничения.
